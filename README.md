# EDA-Python
Exploratory Data Analysis (EDA) on Superstore Dataset using Python. This project explores the Superstore dataset using Python, performing various EDA tasks such as data cleaning, visualization, and statistical analysis. It utilizes libraries like Pandas, Matplotlib, and Seaborn to analyze patterns, correlations, and trends in the dataset.

## Dataset
The raw dataset used for this project is available in the **data** folder. 

- **File Name**: Raw_Dataset.csv
- **File Type**: [CSV]

## Technologies Used
- Python
- Numpy
- Pandas
- Matplotlib
- Seaborn

## Usage
To run the EDA analysis, clone this repository and run the Jupyter notebooks or Python scripts inside the `notebooks` or `scripts` folder.

## Results/Outputs
The EDA process includes visualizations such as histograms, scatter plots, and box plots, which are stored in the **images** folder.
